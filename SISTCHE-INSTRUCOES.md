# Página inicial Sistchê

Pacote pronto para o projeto Next.js existente.

Contém:
- `src/app/page.tsx`: página com fundo preto e logotipo centralizado, responsiva.
- `public/logo-sistche.png`: logotipo fornecido pelo usuário, com fundo removido e recortado para uso na página (mantendo as cores da marca).

## Instalação

Na raiz do projeto `sistche-web`, extraia o conteúdo do ZIP mantendo a estrutura das pastas. Permita substituir `src/app/page.tsx`.

Em seguida:

```bash
npm run dev
```

Abra http://localhost:3000.

Para validar a versão estática: `npm run build`.
